# Open World models

The Open World card loads only these two files. Both come from free editions of Quaternius packs, released as CC0 1.0 (public domain). Attribution is not required. The links are here so the source and license stay easy to find.

## character.glb

Quaternius, Universal Animation Library, standard edition. This file keeps the mannequin and the in-place Idle, Walk, Jog, Sprint, and Jump clips. The rest of the library was removed so the download stays small.

- Pack: https://quaternius.com/packs/universalanimationlibrary.html
- Download: https://quaternius.itch.io/universal-animation-library
- License: https://creativecommons.org/publicdomain/zero/1.0/

## props.glb

Quaternius, Stylized Nature MegaKit, standard edition. The file includes Common Tree 1, Common Tree 5, Rock Medium 1, Rock Medium 3, Flower 3, Flower 4, Grass Common Short, and Clover 1. Textures were resized to 256 pixels and normal maps were left out.

- Pack: https://quaternius.com/packs/stylizednaturemegakit.html
- Download: https://quaternius.itch.io/stylized-nature-megakit
- License: https://creativecommons.org/publicdomain/zero/1.0/
